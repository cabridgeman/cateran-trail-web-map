# Cateran Trail Webmap

This is a qgis version of [this PKCT map](https://www.pkct.org/cateran-trail-accessibility-obstacles-interactive-map).

Known issues:
 - Water crossings with no specified width are currently hidden
 - Obstacles where width clearance is not applicable and height is a bigger concern (eg: stiles), width clearance defaults to 0.1m
